# AI Study Notes Generator

## Project Description

AI Study Notes Generator is a simple web application that helps students convert study material into easy-to-understand notes using AI.

## Features

- Simple Explanation
- Important Points
- Short Notes
- Key Terms & Definitions
- Quiz Questions
- Summary
- Input validation
- User-friendly interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Groq AI API

## How It Works

1. Student enters a study topic.
2. Student enters or pastes study material.
3. The application sends the information to the AI model.
4. The AI processes the material.
5. The application displays the generated notes.

## Project Flow

Python → Flask → API → AI Integration → Prompting → Web Application
